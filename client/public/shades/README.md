# תמונות אמיתיות לגלריית הגוונים

כדי שגלריית הגוונים בדף "עצבי סט" (`/build-a-set`) תציג תמונות אמיתיות במקום האיור, פשוט שימי כאן 6 קבצי תמונה בשמות המדויקים האלה (JPG או PNG, שם קובץ תואם, אותיות קטנות):

| קובץ | גוון |
|---|---|
| `powder-pink.jpg` | ורוד פודרה |
| `wine-red.jpg` | יין אדום |
| `milky-ivory.jpg` | שנהב חלבי |
| `creamy-latte.jpg` | לאטה קרמי |
| `mirror-chrome.jpg` | כרום מראה |
| `piano-black.jpg` | שחור פסנתר |

## המלצות לצילום
- תמונה של יד עם ציפורניים בצורת שקד (almond) וגימור מבריק — זו הצורה/הגימור המוצגים בקטע הזה.
- יחס רוחב-גובה מומלץ **4:3** (לדוגמה 1600×1200 פיקסלים) כדי שהתמונה תתמלא יפה בכרטיס בלי חיתוך מוזר.
- תאורה אחידה בין כל 6 התמונות (אותו רקע/תאורה) כדי שהגלריה תיראה עקבית.
- אפשר להשתמש בקובץ `.png` במקום `.jpg` — רק תעדכני את הסיומת בהתאם ב-`client/src/lib/nailOptions.js` (שדה `image`).

**אין צורך לגעת בקוד.** ברגע שקובץ מופיע כאן בשם הנכון, הוא יוחלף אוטומטית במקום האיור בכל טעינה של האתר. אם קובץ חסר, האתר ימשיך להציג את האיור הקיים במקומו — לא ישבר כלום.
